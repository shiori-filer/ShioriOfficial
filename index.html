Windows で開発・保守をする人のファイラー

探す、読む、コミットする。 ファイラーの中で、待たずに。

エクスプローラーで 118 秒かかった検索が 2.6 秒。数百 MB のログは一度読み込めば、条件を変えても数ミリ秒で絞り込めます。Git のコミットやプッシュも、別のツールを開かずにその場で。

ダウンロード 実測を見る
  • ファイル名の検索約 45 倍エクスプローラー 118 秒 → 2.6 秒
  • ログの絞り込み約 360 倍サクラエディタの Grep 2.25 秒 → 6.3 ms
  • Gitその場でコミット・プッシュ・ブランチの切り替えまで

無料 ・ Windows 10 / 11（64 ビット）・ 管理者の権限は不要 ・ ポータブル版あり

SH01

高速検索。ファイルの中身まで。

ファイル名は打つそばから見つかります。Tab を押せば中身の検索に切り替わり、Excel のセルや図形、Word、PowerPoint、テキストやソースコードの中まで探せます。

  • このフォルダ・このワークスペース・すべてのワークスペースから選べる
  • 全角・半角の違いを気にせず探せる。Shift_JIS のテキストもそのまま
実測

エクスプローラー、サクラエディタと、同じ条件で比べました。

見つかる件数が同じになる条件で、3 回ずつ測りました。Shiori は 2 回目から、さらに速くなります。一度探したフォルダはアプリを閉じても覚えているので、次に起動したあとも、ほぼ 2 回目の速さで出ます。

同じ PC（Core i7-14700F・メモリ 32 GB・NVMe SSD・Windows 11）での実測。エクスプローラーは検索結果が出そろうまで、サクラエディタは Grep の時間（起動の時間は除く、3 回の中央値）。Shiori は 3 回の中央値で、「次に起動したあと」は覚えていた内容を読み込む時間を含みます。

SH02

ログ解析を、一瞬で。

数 GB のログも（PC のメモリに合わせて最大 8 GB）、言葉・時間・レベル・行の形で絞り込み。条件を変えるたびにファイルを読み直すエディターの Grep と違い、一度読み込めば、絞り込みは数ミリ秒で終わります。

  • エラーが何時に多いか、毎日同じ時刻に起きているかが、グラフとマス目でひと目で
  • 選んだ行の前後 5 分、折りたたんだスタックトレースもその場で
  • 絞り込みをタブに残して、左右に並べて時刻をそろえて比べる
  • 正規表現を覚えていなくても、ログに出てくる言葉から選ぶだけ
実測

サクラエディタの Grep と、同じログで比べました。

234 MB・200 万行のログで、同じ言葉を探す時間を測りました。Shiori は最初に 1 回だけログを読み込み（1.2 秒。これだけでもサクラエディタの Grep 1 回より短い時間です）、そのあとは条件を変えるたびに、下の速さで結果が出ます。

サクラエディタGrep0.00 秒
Shiori読み込んだあとの検索—

約 360 倍速く見つかりました

言葉 1 つ
360×2.25 秒 → 6.3 ms
正規表現
260×1.69 秒 → 6.6 ms
どちらかの言葉

なぜ速いのか

  1. 読み込みは 1 回ログは手元に置いたまま。条件を変えても、ディスクから読み直しません。
  2. 全コアで同時にログを分けて、CPU のすべてのコアで同時に探します。
  3. 結果を覚える言葉を打ち足したときや、時間・レベルを変えたときは、前の結果を使うので探し直しません。

A を含み、B は含まない先読みの正規表現を書くか、Grep の結果をさらに Grep する「含む」「含まない」のチップを並べるだけ
2 つの絞り込みを時系列で比べる結果のウィンドウを 2 つ並べ、時刻を目で合わせるタブをドラッグして左右に。スクロールは時刻がそろったまま動く
11/10〜11/12 の 9〜12 時だけ日付と時刻の正規表現を組み立てるマス目を四角く囲む
測った環境

PC: Intel Core i7-14700F（28 論理コア）、メモリ 32 GB、NVMe SSD、Windows 11。データ: UTF-8 のログ 1 ファイル（234 MB・200 万行）。どちらも 2 回目以降（ファイルが OS のキャッシュに載った状態）の、3 回の中央値です。

サクラエディタ 2.4.2 は Grep を始めてから終わるまで（起動の時間は除く）、Shiori はログを読み込んだあと、条件を入れてから結果が出るまでの時間です。見つかった件数は、どの条件も同じでした。

SH03

Git は、ファイラーの中で。

リポジトリを開くと、パスの横にブランチ名と、まだコミットしていない変更の数。Git のパネルから、コミット・プッシュ・プルまで、別のツールのダイアログを開かずにその場で済みます。

  • 変更したファイルにチェックを入れて、メッセージを書いてコミット。「コミットしてプッシュ」も 1 回で
  • ブランチの切り替え・作成、タグ、変更の取り消し、.gitignore の一覧も同じパネルから
  • 「ブランチの流れ」で、分かれて合流してきたブランチを路線図のように。路線名をドラッグしてマージ
  • このフォルダのログと、変更したファイルの差分を左右に並べて（WinMerge があればそちらでも）
  • TortoiseGit と同じ見た目のバッジ（変更・追加・未追跡・無視）
SH04

右クリックを、自分仕様に。

Windows の右クリックメニューから、よく使う項目（7-Zip、TortoiseGit、WinMerge など）だけを Shiori のメニューに直接並べられます。「その他のオプションを確認」を開く手間はもうありません。

  • 設定画面でチェックを付けるだけ。サブメニューもそのまま使えます
  • パスのコピー（12 形式）、日付を付けて複製、ターミナル・エディタで開くも最初から
SH05

ワークスペースを、階層で好きなだけ。

「顧客 › 案件 › 作業」のように、ワークスペースは自由に入れ子にできます。サイドバーには路線図のように並び、ひとつのワークスペースに「ホーム」「設計書」「repo」など、別々の場所にあるフォルダを登録できます。

  • Ctrl+K で、名前やよみ・ローマ字から一瞬で移動
  • ドラッグで並べ替え。色と略称（HKB など）で見分けやすく
  • 一覧のフォルダをサイドバーへドラッグして登録。今あるフォルダ構成からまとめて取り込むことも
SH06

開いていたフォルダは、再起動しても。

タブと左右の分割は、ワークスペースごとに覚えています。別の案件に切り替えると、その案件で開いていたタブに。戻ればさっきの続きから。アプリを閉じて開き直しても、そのままです。

  • 案件ごとに、左右のペインとタブの並びを保存
  • 閉じたタブは Ctrl+Alt+T で開き直せます
SH07

空き容量を、すぐにチェック。

C ドライブ全体（160 万ファイル）を 7 秒で数え、どのフォルダが場所を取っているかを大きい順に。調べている間は、フォルダごとの路線図ができていきます。いらないものは、その場で削除できます。

同じ PC（Core i7-14700F・NVMe SSD）、2 回目以降の実測。dir /s と PowerShell は、Windows の標準の方法でファイルの大きさを合計した時間です。

  • node_modules のような作り直せるフォルダに印。大きいファイル Top 100、重複ファイルの検出も
  • Windows のフォルダは消せないように守ったまま、不要なフォルダはその場でごみ箱へ・完全に削除
SH08

開かずに、中身をプレビュー。

Space キーで、Excel・Word・PowerPoint・画像・Markdown・ソースコードの中身をその場で表示。↑↓ で次のファイルへ。右側の詳細ペインには、表の一部や同じファイルの別の版も出ます。

  • コードは行番号つきで色分け、Markdown は整形して表示
  • 文字コード（UTF-8 / Shift_JIS）と改行もひと目で
SH09

テンプレートで、フォルダ構成ごと。

「01_要件定義」「02_基本設計」…といった案件フォルダのひな形を、フォルダごとテンプレートにできます。新しい案件は名前を付けるだけで、中のフォルダ構成とファイルがそのまま入ったフォルダとして作られます。

  • 右クリックの「テンプレートとして登録」で、どのフォルダでもテンプレートに
  • 空のフォルダもそのまま。作ったあとでも Ctrl+Z で取り消せます
乗換

ほかにも、毎日の「ちょっと面倒」を。

  • アドレス欄が万能

    パスもワークスペース名もファイル名もコマンドも、Ctrl+L から全部ここで。

  • 左右 2 画面

    Ctrl+\ で分割。ドラッグ中は登録フォルダやピン留めが置き場所として出てきます。

  • 画像の変換と編集

    iPhone の写真（HEIC）や WebP を JPG に、何枚かを 1 つの PDF に。スクリーンショットに印を付けてエビデンスにも。

  • ZIP・7z を作る

    右クリックから圧縮。パスワード付きも。形式と圧縮レベルは設定で。

  • 文字コード・改行コードの変換

    Shift_JIS ⇔ UTF-8、CRLF ⇔ LF を、フォルダごとまとめて。変換できない文字は、何行目かを先に知らせます。

  • ショートカットを自分仕様に

    操作ごとに、キーを押すだけで割り当て。重なるときは付け替えます。

終点

Shiori をはじめる

Windows 10 / 11（64 ビット）。インストーラーをダウンロードして実行するだけです。

Windows 版をダウンロード ポータブル版（ZIP）

バージョン 0.3.7（インストーラー、約 8.5 MB）。利用規約に同意のうえお使いください。

ポータブル版（ZIP、約 10.5 MB）はインストール不要です。展開して Shiori.exe を実行するだけで、設定などはそのフォルダに保存します。USB メモリでも持ち歩けます。

初めて実行すると「Windows によって PC が保護されました」と表示されることがあります。その場合は「詳細情報」→「実行」を選んでください。

ワークスペースの設定は、手で編集できるテキストファイル（TOML）に保存されます。Shiori が外部へデータを送ることはありません。
