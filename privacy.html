Privacy Policy

←利用規約 トップ→

2026年11月14日 制定

Windows 用ファイラー「Shiori」（以下「本ソフトウェア」）は、利用者の情報を集めません。設定もフォルダの一覧も、すべて利用者のパソコンの中だけに保存されます。以下に、何がどこに保存され、何が外に出るのかを書いておきます。

  1. PP01

    本ソフトウェアは通信しません

    本ソフトウェアがインターネットに接続することはありません。利用状況の送信、更新の確認、広告の表示は行いません。プレビューで Markdown を表示するときも、外部の画像は読み込みません。

  2. PP02

    パソコンに保存するもの

    本ソフトウェアは次の情報を、利用者のパソコンにだけ保存します。

    • ワークスペースと登録したフォルダ、設定: %APPDATA%\jp.shiori.app\ の workspaces.toml と settings.toml
    • よく開くフォルダの記録（移動の候補を並べるため）: 同じフォルダの usage.json
    • 開いていたタブと履歴、列の幅など画面の配置（再起動しても元に戻すため）: %LOCALAPPDATA%\jp.shiori.app\
    • 圧縮ファイルの中から開いたファイル: 一時フォルダ %TEMP%\shiori-zip\

    アンインストールしたあと、これらのフォルダを削除すると、すべて消えます。

  3. PP03

    利用者の操作で起きる通信

    次の通信は本ソフトウェアではなく、Windows やほかのソフトウェアが行います。

    • 共有フォルダ・ネットワークドライブ・OneDrive などを開いたときの、Windows によるファイルの読み書きや同期
    • 本ソフトウェアから起動した Git、エディタ、右クリックメニューの項目などが行う通信（それぞれの提供元の方針に従います）
    • Microsoft Edge WebView2 ランタイムが Microsoft に送る診断データ（Windows の「診断データ」の設定に従います）
  4. PP04

    紹介サイトについて

    このサイトは Cookie を使わず、アクセス解析も入れていません。ただし、表示のために次のサービスを使っており、閲覧すると IP アドレスやブラウザの種類などがそれぞれの事業者に送られます。

    • GitHub Pages（サイトの配信）と GitHub Releases（インストーラーの配布）: GitHub のプライバシーに関する声明
    • Google Fonts（文字の表示）: Google のプライバシーポリシー
  5. PP05

    第三者への提供

    提供者は利用者の個人情報を集めていないため、第三者に提供することもありません。

  6. PP06

    このポリシーの変更

    このポリシーは変更することがあります。変更後のポリシーは、このページに掲載した時点から効力を持ちます。

お問い合わせ

このポリシーについてのご質問は GitHub の Issues へお寄せください。Issues は誰でも見られるため、個人情報や社内の情報は書かないでください。
